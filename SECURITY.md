# Security policy

Please **do not open a public issue** for a vulnerability. Report it privately through GitHub's [private vulnerability reporting](https://github.com/gpixtm/api/security/advisories/new) for this repository, with the affected version or commit, reproduction steps and the impact you expect.

We aim to acknowledge reports within a week and will keep you informed until a fix is released. Only the latest `main` is supported.

Security issues in the Android app can be reported the same way on [gpixtm/app](https://github.com/gpixtm/app/security/advisories/new).
